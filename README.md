# MARK II — STARK OS

Персональный ИИ в стиле лаборатории Тони Старка. Живой сайт: https://tobirama2904-cell.github.io/jarvis-ultron/

## Персоны
JARVIS · FRIDAY · ULTRON · VISION — у каждой свой характер, цвет интерфейса и голос.

## Возможности
- **Чат с нейросетью** (Agnes AI): стриминг ответов, вызов инструментов (время, счёт, погода, курсы, Википедия, новости, заметки, задачи, напоминания)
- **Голос**: непрерывное распознавание, русские голоса озвучки, wake-word (Джарвис/Пятница/Ультрон/Вижн), режим диалога, анти-эхо, кнопка ⏹
- **Зрение**: камера (фронт/зад, свой цикл без camera_utils), жесты ✋ стоп / ✊ микрофон, приветствие по лицу (MediaPipe, грузится лениво)
- **Творец**: генерация картинок со стилями, раскадровка ×3, галерея
- **Польза**: утренний брифинг, совет троих, новости с дайджестом, переводчик, задачи, напоминания (звук + уведомление)
- **STARK OS**: boot-заставка, arc-реактор на canvas (пульс речи, цвет персоны), SFX-синтез, телеметрия, палитра команд (Ctrl+K), диагностика, экспорт памяти

## Ключ API
Вставь ключ Agnes AI в ⚙️ Настройки (хранится только в браузере, в репозитории ключей нет).
Без ключа работают: время, счёт, погода, курсы, новости, задачи, напоминания.
