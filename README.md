# LEGION — MARK III (v18)

Персональный ИИ-агент в браузере: чат, зрение, голос, память, файлы и фоновые задачи.
Нейросеть — **Agnes AI** (бесплатный безлимит, ~20 запр/мин). Всё остальное — локально и бесплатно навсегда.

**Живое демо:** https://tobirama2904-cell.github.io/jarvis-ultron/

## Что внутри

| Раздел | Возможности |
|---|---|
| 💬 Чат | Диалог с инструментами (погода, курсы, новости, напоминания), 4 персоны: JARVIS / FRIDAY / ULTRON / VISION |
| 🎬 Студия | Анализ фото, видео (покадрово), PDF, текстов, аудио. Drag & drop |
| 🧠 Память | Профили (Босс, Гость…), факты, вкусы, проекты, события, файлы. Локальное + LLM-извлечение, поиск, `/mem` |
| ⚡ Легион | Очередь фоновых задач с живым прогрессом. `/deep` — черновик → критика → финал + скачивание `.md` |
| 🎙 Голос | Hold-to-talk, постоянный режим, живой транскрипт, проверка микрофона/озвучки, журнал голоса |

Плюс: проактивный агент (здоровается, замечает долгое молчание), WATCH-режим камеры
(детект движения + разбор кадров), 116 полезных команд (игрушки скрыты), 2 темы
(Фарфор / Обсидиан), PWA, офлайн-кэш, кэш моделей.

## Быстрый старт

1. Открой демо (или `python3 -m http.server 8099` в этой папке).
2. Вставь ключ Agnes AI в ⚙️ Настройки (взять: platform.agnes-ai.com). Без ключа работают: время, счёт, погода, курсы, новости, задачи, напоминания, память.
3. Разреши микрофон/камеру при первом использовании голоса.

## Команды

`/deep тема` · `/img описание` · `/story идея` · `/council вопрос` · `/brief` · `/news` · `/tr текст` ·
`/remind 10 текст` · `/todo текст` · `/mem запрос` · `/watch` · `/theme` · `/persona friday` ·
`/diag` · `/clear` · `/help` — и ещё 116 сил (`/help`, Ctrl+K).

Голосом: «Джарвис, …». Жесты: ✋ ладонь — замолчи, ✊ кулак — микрофон вкл/выкл.
